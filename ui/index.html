About this demo

A customer-facing assistant built around one rule: it answers from the laboratory’s own documents, or it says it cannot. A router reads each message and hands it to one of three specialists - information, appointments, complaints.

Try asking

The last two are the interesting ones - it declines to interpret a result, and declines a service the documents do not cover.

Appointments

Bookings here are clash-checked and confirmed against an in-memory diary. A public demo should not hold write access to a real calendar, so no OAuth token is deployed. The calendar is a swappable backend - run it locally with credentials and the same code writes to Google.
